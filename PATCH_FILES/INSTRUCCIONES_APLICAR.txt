PASOS PARA EJECUTAR LA COMPILACIÓN
=============================================================================

1. Ve a GitHub Actions
   https://github.com/P-Renault/agenda-ya-android/actions

2. Selecciona el workflow

3. Haz click en "Run workflow"

4. Selecciona la rama
   fix/android-packaging

5. Haz click en "Run workflow"

6. Espera a que se complete (30-40 minutos aproximadamente)

7. Descarga el artefacto
   - Click en el workflow completado
   - Baja hasta "Artifacts"
   - Descarga "AgendaYA-Android-debug-APK"
   - Descomprime el ZIP
   - El APK está en: app-debug.apk

VERIFICACIÓN LOCAL (OPCIONAL)
=============================================================================

Antes de ejecutar el workflow, puedes verificar localmente que todo está correcto:

1. Instala Node.js 20
   https://nodejs.org/ (descarga v20.x)

2. En la raíz del proyecto, ejecuta:
   $ npm ci
   $ npm run verify:web

3. Si todo está correcto, verás:
   ✓ Verificación de web assets OK: login, dashboard, recursos, Supabase y Capacitor configurados correctamente.

4. Si hay errores, verás un mensaje claro del recurso que falta:
   ERROR: Falta www/login.html
   ERROR: El appId debe ser "cl.agendaya.app"
   etc.

=============================================================================
TROUBLESHOOTING
=============================================================================

PROBLEMA: El workflow no aparece en el menú
SOLUCIÓN: Git requiere que hayas hecho push de la rama. Verifica:
  $ git branch -a | grep fix/android-packaging

PROBLEMA: Error "Falta www/login.html"
SOLUCIÓN: Los archivos web deben estar en la carpeta www/
  - Verifica que P-Renault/somos-agenda esté sincronizado
  - Copia los archivos de www/ si es necesario

PROBLEMA: "El appId debe ser cl.agendaya.app"
SOLUCIÓN: Revisa que capacitor.config.json tenga:
  {"appId": "cl.agendaya.app", "appName": "Agenda YA", "webDir": "www"}

PROBLEMA: Build timeout en GitHub Actions
SOLUCIÓN: El workflow tiene timeout de 45 minutos. Si excede:
  - Revisa los logs (click en el job fallido)
  - Puede ser por versión de Gradle o dependencias
  - Intenta ejecutar localmente primero

PROBLEMA: No puedo hacer push a P-Renault/agenda-ya-android
SOLUCIÓN: 
  - Necesitas permisos de escritura en ese repo
  - Alternativa: Haz fork a tu usuario y aplica los cambios allí
  - Luego abre PR desde tu fork
